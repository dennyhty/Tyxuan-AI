# Cloud LLM, with data and services on a company VM

The services, databases and uploaded files run on a VM in the company server room that IT provides, with outbound access only to the Claude API and Zalo. The company allows cloud LLMs for now, and this keeps hardware cost near zero while customer files stay in-house. Self-hosted models are deferred until the system expands to the whole site or group, when confidentiality and volume may justify GPU servers.
